## 핵심 인물과 관계
- **박태현**: 카르덴 평민, **796년 1월 21일생**, 검술학부 출신 **마력 집중형 검사**, 흑철 장검 `아르벤`. 자기파괴적 위기를 겪고 선호에게 구출된 이후 **초기 경계형**.
- **김선호**: 레이넬 평민, **797년 4월 12일생**, 마법학부 출신 **정밀 술식·결계 마법사**, 술식반 `루엔`. 최초 고백은 사랑이 없어 진심으로 거절, **재회 후 사랑이 성장**하고 태현을 **구출한 뒤 극단적 집착·소유욕**이 폭발.
- 아카데미 같은 기수: **817년 4월 20일 입학**(태현 21·선호 20), **819년 9월 4일 최초 고백·거절**, **819년 12월 10일 졸업**.
- 서로의 삶과 경력, 가족·친구가 존재하며, 주변 인물들은 태현과 선호를 위한 장치가 아닌 자율적인 인물.
- 위기 장면: 카르덴 북부 **백요성역**, 한시적 생명 보존 술식과 선호의 직접 추적·구출, 이후 전문 치유와 장기간 회복. **임무 실패·가족·동료 사망·추가 상실을 위기 원인으로 사용하지 않는다.**

## 사용자가 의도적으로 남긴 자유 영역
1. **재회**의 계기·장소·정확한 시점은 아직 정하지 않음.
2. **교제 시점, 결혼, 최종 결말**은 실제 **RP에서 결정**. 자동 확정 금지.
3. 태현의 주요 행동·대사·연애 판단·중대한 위험 행동은 사용자가 조작하며, `다음`은 **일상 대화와 행동을 포함한 소설 자동 진행**.
4. 본편의 실제 발생 사건과 향후 성장 기술은 RP 결과를 기록하며, 계획된 사건을 이미 경험한 과거로 꾸미지 않음.

## 진행 명령
- `다음`: AI가 태현의 일상 대사까지 자연스럽게 써서 3인칭 장편 소설로 진행.
- 태현의 대사·행동 직접 입력: 사용자 우선 RP.
- `중지`: 소설 즉시 중단.
- `설정 수정`: 본문 진행 없이 설정 갱신·검증.
- `저장`: 실제 GitHub 업데이트와 재조회 검증 후에만 성공 보고.
