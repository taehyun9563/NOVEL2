## 핵심 정본
- 박태현이 김선호에게 고백했으나 당시 선호는 연애 감정이 없어 거절한다. 태현은 이후 의도적으로 거리를 두고, 두 사람은 졸업 후 단절되었다가 재회한다.
- 태현의 삶의 의지 상실, 자기파괴적 위기, 선호의 직접 구출은 기획의 중심 사건이다. **별도의 임무 실패, 동료·가족의 죽음, 추가 상실 사건을 절망의 원인으로 넣지 않는다.**
- 선호의 **사랑은 재회 이후 구출 전부터 서서히 형성**된다. **극단적 집착·소유욕은 태현을 구출한 이후 폭발**한다.
- 구출 이후 태현은 **경계형**으로, 선호의 고백을 곧바로 믿거나 받아들이지 않는다. 단 구체적 대사와 중대한 선택은 사용자 권한.
- **회귀는 없는 단일 시간선**. 기존 `NOVEL_LOVE`의 현대 IT 학원, 취업 날짜, 2028년 구조 사망 및 회귀 설정은 **이 작품에 적용하지 않는다**.
- **세계관 종류는 정통 하이 판타지 확정**. 세르디아 명칭과 세부 국가·인물·능력 등은 2~7단계 설계안에서 가져왔으며 최종 잠금 전 변경 가능.
- 메인 로맨스는 태현↔선호. 서브 히로인과의 교제는 필수 아님.

## 운용 명령
- `다음`: 3인칭 소설 자동 진행. **태현의 일상 대사도 작성**, 질문마다 멈추지 않는다.
- 태현의 대사·행동 직접 입력: 사용자의 의도를 우선해 RP로 전환.
- `중지`: 소설 즉시 중단.
- `설정 수정`: 본문 없이 설정 정합성 검토.
- `저장`: 실제 GitHub 저장과 재조회에 성공한 뒤에만 완료 보고.
- **고백 수락·이별·결혼·자기파괴 등 중대한 주인공 선택을 AI가 독단적으로 확정하지 않는다.**
