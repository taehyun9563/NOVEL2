# 2단계 — 《세르디아》 정통 판타지 세계관·문명·아카데미
> 상태: **정통 판타지 선택 및 세르디아 세계 설계 진행 확정**. 세부 고유명사와 기술은 2단계 설계 기준안이며 추후 수정 가능.

## 세계의 법칙
| 항목 | 내용 |
|---|---|
| 세계명 | 세르디아 |
| 중심 대륙 | 아스테른 |
| 시대 | 마력·검술·마법·마도공학이 발전한 하이 판타지 문명 |
| 세계 성격 | 평소 생활은 밝고 풍부하며, 비극 국면은 어두워짐. 종일 절망적인 다크 판타지 아님 |
| 사회 | 왕정·자치도시·귀족·평민·길드·상인 공존 |
| 종족 | 인간 중심. 엘프·드워프 등도 존재 가능 (비중 미정) |
| 종교 | 다양한 신앙 존재, 신의 직접 개입 미확정 |
| 부활·회귀 | 죽은 사람의 부활은 불가능. **이 작품에 시간 회귀 서사 없음** |
| 공통 규범 | 독립된 개인의 직업·가족·연애·학업 생활 존재 |

## 주요 정치 세력
| 영역 | 국가·도시 | 통치·경제·문화 | 특기 |
|---|---|---|---|
| 북부 | **카르덴 왕국**, 수도 바스테인 | 산악 요새, 기사 전통, 평민 실력자 진출 가능 | 검술·기사단·방어술 |
| 동부 | **레이넬 왕국**, 수도 엘시온 | 마도 연구·학술원, 마법 특허와 기술 경쟁 | 마법·술식 |
| 서부 | **벨루아 왕국**, 수도 마르벨 | 곡창·상업·예술·축제·외교 | 마도공학·무역 |
| 남부 | **루메리아 자유도시 연합**, 의회 소재 세일라 | 4개 자치도시의 연합, 상단·모험가 길드 발달 | 무역·제작·길드 |
| 중앙 | **아르테아**, 독립 중립도시 | 의회·독립 행정·치안, 공동 중립 협약 | 종합교육·문화교류 |
| 기타 | 변방 소국 | 존재하나 구체 설정 미정 | 필요 시 설계 |

**정합성**: 아르테아는 루메리아 연합의 4개 자치도시 중 하나가 **아니다**. 세 왕국과 루메리아 연합이 아르테아 독립성을 공동 보장한다. 각국이 상시 전쟁 중이지 않으며 외교·교역·기술 경쟁을 지속한다.

## 아르테아 및 루미나르 중앙 아카데미
| 항목 | 운영안 |
|---|---|
| 기관 | 루미나르 중앙 아카데미 |
| 소재지 | 중립도시 아르테아 |
| 학제 | 3년 정규 과정, 성인 청년층 중심, 특례 입학 가능 |
| 학부 | 검술·마법·마도공학·치유·인문행정 |
| 신분 | 평민·귀족 모두 지원, 재능/성적/경제 사유 장학 |
| 목적 | 학문·전문 직업·실무 교육, **군사학교 아님** |
| 생활 | 공통 교양·실습·동아리·축제·식사·도시 데이트·동문 모임 |
| 진로 | 졸업 후 국가·길드·연구·자영업 등 자유 선택 |
| 치안 | 별도 도시 경비대; 아카데미 교수가 군 지휘관이 아님 |

학부 간 공동 강의와 실습을 통해 태현과 선호가 친분을 쌓고 졸업 이후 동문 행사에서 다시 만날 수 있다. 고백 장소·재회 계기는 아직 미확정이며 작위적인 정치 음모를 둘의 관계에 필수로 얹지 않는다.

## 삶의 인프라
- 주거: 기숙사, 가정집, 도시 주택, 여관, 소형 공동 거주.
- 상업·여가: 찻집, 식당, 시장, 축제, 공연, 공원, 여행.
- 이동: 마차·일부 마력 차량·등록된 도시 간 전송 시설. 개인이 임의로 어디든 순간 이동할 수는 없음.
- 연락: 마도 통신구, 편지, 전령. **광역 마력 난류·변방에서 통신 불안정**.
- 치안·직업: 도시 경비대, 기사단, 길드, 연구원, 치유원, 상업 활동.
- 공용 화폐: 금·은·동화 (세부 환산율 미정).

## 마력·치유·생사 규칙
1. 마력은 세계와 생명에 존재하며 개인마다 적성·제어력·축적량이 다르다.
2. 검술에는 신체·무기 강화, 검기, 검강 등이 존재. 마법은 술식을 이용해 현상을 구현.
3. 상위 강자는 대규모 전투에 영향 줄 수 있지만 **불멸이 아니며 피해와 죽음은 현실적인 결과**.
4. 일반 부상은 치유 마법으로 호전될 수 있으나 중상은 전문적 치료와 장기 회복이 필요하다.
5. 생명 유지 마법·술식은 한시적 보조일 뿐 완전 치유·부활·정신 회복을 보장하지 않는다.
6. 마법으로 슬픔·후회·사랑·트라우마를 즉시 없애지 못한다.
7. 추적 마법은 기존 마력 흔적을 찾을 수 있으나 거리·시간·기상·마력 난류 영향을 받는다.

## 모험과 위험 지역
- 카르덴 **북부 설원**: 혹한·마력 폭풍·폐허 유적.
- 레이넬 **동부 고대 유적**: 오래된 술식과 연구의 장.
- 벨루아 서부 **대삼림**: 생태·마물·교류.
- 루메리아 남부 외해: 해역·섬·항해.
- 중앙 **마력 난류 지대**: 탐지·통신 방해.
- 이 지형들은 배경 설정이지 주인공에게 무조건 임무·전쟁을 부과하는 장치가 아니다.
