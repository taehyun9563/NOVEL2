# 8단계 — 《세르디아》 최종 정합성 감사 및 결정 상태
> 2026-11-08 / NOVEL2 새 저장소 / 1~7단계 설계 감사

## 감사 요약
- **검증 목적**: 1~7단계 문서 및 사용자 최신 변경을 대조하여 명시적 결정을 누락하지 않고, 제안과 미확정을 사실처럼 잠그지 않으며, 소설 시작 전 모순을 제거.
- **검증 결론**: 큰 구조의 충돌 해결. **세계관 세부·주인공 전공·기술·정확한 날짜·실종 장소 등 일부가 미확정**이며, 이들은 미정으로 표시했으므로 본편 시작 전 추가 선택 가능.
- **저장 원칙**: 확인된 사용자 결정을 정본으로 우선 적용. 후속 선택이 수정하면 관련 문서를 함께 변경.

## 2. 정합성 결함 및 조치
| 검증 쟁점 | 위험 | 조치 결과 |
|---|---|---|
| 구작 `NOVEL_LOVE`과 혼합 | 현대 IT 취업학원/2026 재회/2028 사망·회귀를 세르디아에 잘못 이식 | **분리**. 세르디아는 단일 시간선 정통 판타지 |
| 태현의 절망 원인 | 5~6단계 초안의 '임무 실패나 상실 사건'이 최신 사용자 삭제 요청에 위배 | **제외**. 감정 관계·단절·재회·고립에 초점 |
| 태현의 역할 | 소설 `다음`에서 말없이 대기하는 주인공이 되거나 RP에서 AI가 중대 선택 | **자동 모드 분리**, 일상 대사 자동, 주요 결정 사용자 우선 |
| 선호의 집착 시점 | 최초 고백·재회부터 극단적 집착 오배치 | **구출 이후에만 폭발**. 그 전에 사랑 형성 가능 |
| 선호의 사랑 이유 | 자해가 사랑을 보상받는 방법으로 오독 | **구출 전부터 감정 축적**. 사건은 자각의 계기 |
| 선호 수색 독점 | 독립적 조연들이 능력이 없거나 방관 | **구출 선호 주도 + 주변의 합당한 능동 지원** |
| 생사·치유 | 치유 마법으로 부활·심리적 즉시 완치 | **부활 불가**, 치유의 제한·회복 기간 유지 |
| 학년과 나이 | 태현 21·선호 20이지만 학년 차이가 발생할 위험 | **같은 입학 기수 817~819년 3년 과정**, 한 살 차이 |
| 3왕국/연합/중립도시 | 루메리아 4자치도시와 아르테아 중복 | 아르테아는 **별도의 독립 중립도시** |
| 3단계 능력안 | 태현 검사·선호 마법사를 승인된 확정값으로 취급 | **설계 기준안**으로 표기, 3단계 보완 가능 |
| 4단계 인물안 | 제안한 이름·직업을 연애 결정으로 오인 | **프로필 기준안**, 관계 결과는 유동적 |
| 고정 구출 vs 자유 RP | 정해진 구조 사건 때문에 사용자 선택을 몰래 덮어쓸 위험 | **충돌 시 분기/수정 명시**, 사용자 행동 강행 금지 |
| 서브 히로인 | 반드시 관계 경쟁·교제를 강제 | **교제 불필요**, 독립된 인물로 운영 |
| 후반부 리듬 | 구출 직후 모두 완치·연인화 | **구출 이후의 집착·경계·신뢰 회복에 긴 호흡** |
| 정확한 만 나이·요일 | 출생일 없이 817/822/823 나이를 확정해 시간 충돌 | **대략적 나이**만 표기, 생일과 날짜 미정 |

## 3. 문서별 우선순위
- `01`: 태현·선호 감정선과 확정 관계 태그.
- `02`: 세계관과 사회·기술·학교의 설계 기준.
- `03`: 주인공의 능력 설계안과 공통 경지.
- `04`: 조연과 인물 간 기본 접점.
- `05`: 장편 8부와 사건의 가상 연표.
- `06`: 위기·실종·구출·구출 후 집착.
- `07`: 실제 소설·RP 진행 권한.
- **`08`**: 확정·제안·미확정 및 충돌 해결의 최종 감사 기준.
- 사용자 최신 명시적 수정이 모든 파일보다 우선한다. 해당 변경 시 관련 문서를 일관되게 업데이트한다.

## 4. 아직 필요한 선택 (본편 준비용)
| 항목 | 상태 | 왜 남겨 두는가 |
|---|---|---|
| 태현/선호의 정확한 생년월일·외형 | 미정 | 나이 계산 및 장면 일관성 |
| 검사·마법사 기본안의 최종 승인 | 미정 | 능력/구출 전개의 기반 |
| 태현·선호의 단계별 경지·기술 | 미정 | 전투·구출 강도 |
| 재회 계기 및 실종 직전의 구체적 관계 | 미정 | 후회·사랑 자각의 설득력 |
| 실종 장소·상황·구조 세부 | 미정 | 사용자 자기파괴 사건의 구체적 선택 존중 |
| 구출 후 관계 확정·결말 | 미정 | RP 자유도 유지 |
| 본편 첫 장면 및 시점 | 미정 | 사용자가 시작할 때 결정 |

이 중 아직 결정하지 않은 것을 이야기 도중 무단 확정했다며 과거 설정으로 주장하지 않는다. 사용자 요청에 따라 단계별로 확정할 수 있다.

## 5. 금지된 추가 설정
- 태현의 심리적 위기를 합리화한다며 **임무 실패, 동료의 죽음, 가족의 죽음, 별도의 극적 상실을 새 원인으로 자동 부여 금지**.
- 과거 선호의 최초 거절을 사실은 사랑했거나 거짓말이었다고 소급 변경 금지.
- 선호가 구조 이후 처음으로 태현을 사랑한 것처럼 표현 금지.
- 이전 작품의 현대 취업·월급·아파트·차량·회귀·패왕 기술을 자동 도입 금지.
- 이미 사용자 직접 입력으로 결정한 태현의 중요한 대사·행동·거부를 AI가 임의로 뒤집지 않는다.
