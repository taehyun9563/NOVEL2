# 8단계 — 《세르디아》 정합성 최종 검증 v2.0
> 검증일: 2026-11-08 (KST)  
> 적용: 사용자 최신 결정 **"나머지는 알아서 설정. 재회는 제외하고 교제 시점, 결혼, 결말은 RP 하면서 결정"**  
> 의미: 인물의 구체 외형·출생·전공·기본 기술과 경지·위기 무대·구출 기본 규칙을 확정한다. **재회 계기·정확한 재회 시점과 교제 시점·결혼·최종 결말은 확정하지 않는다.**

## 2. 의도적으로 열어 둔 항목
| 항목 | 운영 원칙 |
|---|---|
| **태현과 선호의 재회** | **계기·장소·정확한 시점 미정**. 이전 문서의 '동문 모임·공동 임무'는 가능성이지 채택이 아니다. 재회의 방식은 사용자 후속 결정 또는 그때의 RP 합의로 정한다. |
| **교제 시점** | 두 사람의 명확한 의사에 따라 **RP에서 결정**. 선호의 구출 또는 집착으로 자동 교제 시작 금지 |
| **동거·결혼** | **RP에서 결정**. 구출 이후 몇 개월/몇 년 내 결혼이라는 예정 사건 없음 |
| **최종 결말** | **RP에서 결정**. 결혼·해피엔딩을 미리 확정하지 않음 |
| **태현의 중대한 대사·선택** | 사용자 직접 결정권, `다음` 모드는 일상 대사만 자동 |
| **재고백·재거절** | 자동 사건 아님. 사용자의 선택과 당시 선호의 감정에 따라 성립 |
| **4경지 이상 성장과 신규 기술** | RP 사건·훈련·합의에 따라 진행. 현시점 3경지 초과 자동 성장 없음 |
| **위기 당시 구체적 자기파괴 행동과 대사** | 사용자 직접 RP 조작권 유지. 심각한 위기·장소·구출 구조는 기준 설정 |
| **구출 실제 세부 날짜** | 823년 11월이 사건의 기본 시기. 정확한 시간·세부 일정은 장편 진행 기록에서 확정 |

## 3. 충돌 감사 및 조치
| 문제 | 정합성 조치 |
|---|---|
| 입학 21세/20세 vs 3월 입학이면 선호 생일 전 19세 | **입학을 817년 4월 20일로 통일**. 태현 1/21·선호 4/12 모두 생일 경과 |
| 817~819의 학제가 3년인지 혼선 | 817·818·819 3개 학년도, **819년 12월 졸업**으로 통일 |
| 태현 '세계 최강 패왕'을 타 작품에서 자동 가져올 위험 | 명시적으로 **도입하지 않음**. 태현은 위기 시 3경지 상위 검사 |
| 선호가 전문 치유사처럼 완전 치유하는 문제 | 선호의 `맥정`은 **응급 안정화만**, 전문 치유원·치료 필요 |
| 선호의 추적 능력이 무제한 위치 탐지로 변질 | `잔향독해`는 마력 흔적의 해석. 관문 기록·동료의 정보와 결합 |
| 백요성역의 생존술식이 자해의 성공 보장처럼 보이는 문제 | **자동·한시적 보존**일 뿐, 부활·불멸·완치 기능 없음 |
| 처음 고백한 순간부터 선호가 사랑·집착했다는 오류 | 최초 거절은 진심, 사랑은 재회 **이후** 점진적, 극단적 집착은 **구출 이후** |
| 태현 위기에 임무 실패나 가족·동료의 사망을 추가 | **사용자가 삭제**한 설정이므로 전면 금지 |
| 재회 계기를 임의 확정할 위험 | 사용자 요청에 따라 명확한 **미정**으로 유지 |
| 연애·결혼·결말을 미리 정하는 오류 | **모두 RP에서 결정**, 고정 연표 없음 |
| 고정 구출과 태현의 행동권 충돌 | 사용자의 직접 선택을 몰래 덮어쓰지 않고 필요한 분기/설정 조정 |
| 선호의 과격한 집착을 부정적 결과 없이 낭만화 | 경계 침범과 통제 행동은 실제 갈등·반응·결과를 남김 |
| 시간 이동 때 인물이 정지 | 7단계 규칙에 따라 각자의 생활·감정·약속 유지 |
| 구작 `NOVEL_LOVE` 시간 회귀·2028 사망을 혼동 | 세르디아는 **독립 단일 시간선**, 회귀 없음 |

## 4. 문서 간 우선순위
1. **사용자 최신 명시적 지시** — 재회·교제·결혼·결말 미확정 포함.
2. **본 문서**의 확정/미정 구별과 충돌 조치.
3. `settings/01`: 관계 태그·감정선.
4. `settings/02`: 세르디아 문명·아카데미·마법 법칙.
5. `settings/03`: **주인공 프로필과 고정된 능력·경지**.
6. `settings/04`: 가족·친구·조연의 기본 설계안.
7. `settings/05`: 사건 시간선과 8부 구조. 재회는 **방법/정확한 시점 미정**.
8. `settings/06`: 백요성역 위기·추적·구조.
9. `settings/07`: 소설·RP 전환·태현의 행동권.
10. `story/PROGRESS.md`: **실제로 진행된 본편 기록**. 계획과 실제 사건을 혼동하지 않는다.

## 5. 검증 결론
- 핵심 프로필·주인공 기본 전투·아카데미 학사·백요성역 구출 구조: **설정 확정 및 논리 정합성 확보**.
- **의도적 공란**: 재회 계기/장소/정확한 시기, 교제 시점, 결혼, 최종 결말. 이들은 오류나 누락이 아니며 사용자 의도에 따라 열린 상태.
- 본편은 **미개시**. 소설 출발·전개 과정에서는 사건의 발생을 계획만으로 단정하지 않는다.
