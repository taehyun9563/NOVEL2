# 3단계 — 주인공·능력 체계
> 상태: **태현 경계형 / 선호 구출 후 극단적 집착은 확정**. 전공·외형·출신·무기·최종 경지는 **현재 채택된 설계안(변경 가능)**이다.

## 박태현
| 항목 | 설계 기준 |
|---|---|
| 이름 | 박태현 |
| 성별 | 남성 |
| 학원 입학 당시 나이 | 21세 (선호보다 1세 연상) |
| 신분·출신 | 카르덴 왕국 평민 |
| 학부 | 루미나르 아카데미 검술학부 |
| 외형안 | 짧은 검은 머리, 검은색 계열 제복, 차분한 인상 |
| 기본 전투 | 마력 강화형 근접 검사, 고속 검술 |
| 무기안 | 검은 장검 |
| 강점 | 뛰어난 실전 적응력·검술 감각·높은 성장 잠재력 |
| 제한 | 피로·마력 소모·상성·부상·회복 필요 |
| 특수 출생 | 신의 가호·숨겨진 전생·특수 혈통 없음(현 설계) |
| 독립적 삶 | 진로·모험·우정·직업·연애 판단은 사용자 선택 |
| 심리 | 자기파괴적 위기는 핵심 서사, **구출 후 경계형** |
| 최종 능력·경지·고유 기술 | **미확정**. 세계 최강으로 자동 확정하지 않음 |

태현의 일상 성격·화법·감정 표현은 사용자에게 결정권이 있다. `다음` 소설 모드에서는 일상적이고 가벼운 반응은 AI가 서술하되 중대한 사랑·자기파괴·수락은 임의 확정하지 않는다.

## 김선호
| 항목 | 설계 기준 |
|---|---|
| 이름 | 김선호 |
| 성별 | 여성 |
| 학원 입학 당시 나이 | 20세 (태현보다 1세 연하) |
| 신분·출신 | 레이넬 왕국 평민 |
| 학부 | 루미나르 아카데미 마법학부 (태현과 **동기**, 학년 같음) |
| 외형안 | 긴 다크브라운 웨이브, 따뜻한 인상, 제복 |
| 기본 전투 | 정교한 술식·결계·중거리 마법 |
| 강점 | 제어·해석·판단·복수 술식 운용 |
| 기본 치유 | 응급 치유술 가능; 전문 치유사 수준 아님 |
| 마력 탐지 | 가능하나 흔적·거리·기후·난류 제약 |
| 일상 성격 | 밝음·다정함·장난기·적극성·독립성 |
| 사랑·집착 | 구출 이전 사랑 형성, **구출 이후 집착·소유욕 극대화** |
| 고유 기술·최종 경지 | **미확정** |

선호는 자체 직업·친구·가족·목표가 있으며, 태현의 사랑을 받기 위한 장치가 아니다. 구출은 선호의 직접 행동·동료 협력·치유사의 전문 지원으로 성립한다.

## 공통 전투 5경지 기준
| 경지 | 공통 수준 | 검사 | 마법사 |
|---|---|---|---|
| 1 | 입문 | 기초 검술·마력 강화 | 기초 술식 |
| 2 | 숙련 | 검기·고속 전투 | 중급·복수 술식 |
| 3 | 대가 | 검강·고위 검술 | 고위 마법·광역 술식 |
| 4 | 초월 | 독자적인 초월 검술 | 대마법·고유 대술식 |
| 5 | 극의 | 국가 전략급 위협 수준 | 국가 전략급 궁극마법 |

- 경지는 힘의 대략적 범주이지 자동 승리 규칙이 아니다. 상성·준비·현장 상황에 따라 결과가 달라진다.
- 5경지라도 불사나 무적을 보장하지 않는다.
- 전쟁·왕국·강자 대결 자체가 작품의 최상위 목표가 되지 않도록 연애 서사를 중심에 둔다.
- 주인공들의 구체적 시점별 실력과 고유 기술은 **미확정**. 이전 《마도문명》의 패왕, 각성 단계, 흑월 등 능력을 자동 이식하지 않는다.

## 인물·시간선 정합성
- 817년 태현 21세·선호 20세로 **같은 학년에 입학한 1년 차이 동기**. 출생 연도·생일·정확한 날짜는 미정.
- 817·818·819 정규 3년, 819년 말 졸업. 이후 독립적인 진로.
- 현재의 `검사 태현 × 마법사 선호`는 **3단계 추천을 이어받은 설계안**이지 사용자가 최종 잠금한 선택은 아니다. 변경할 때 관계와 구출의 정합성도 함께 검토한다.
