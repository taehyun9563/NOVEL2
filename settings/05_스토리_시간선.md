# 5단계 — 장편 8부 스토리·시간선 v2.0
> 2026-11-08 개정. 사용자 위임으로 **생일·기본 경지·학교 졸업과 비극 구간의 기준 시점**을 구체화. **재회 계기·정확한 재회 시점**, **교제 시점·결혼·결말은 의도적으로 미확정**.

## 1. 작품 핵심 흐름
루미나르 중앙 아카데미 같은 기수 입학 → 친분·태현의 사랑 → 고백·선호의 진심 어린 거절 → 태현의 의도적 무시와 단절 → 졸업 후 독립적인 삶 → **재회(방법·날짜는 미정)** → 태현의 상처와 선호의 점진적 사랑 형성 → 태현의 자기파괴적 위기·실종 → 선호의 직접 구조 → 선호의 **극단 집착·소유욕** 폭발, 태현의 **경계형** 반응 → 관계의 회복·연애 가능성.

**회귀·환생·기존 NOVEL_LOVE 현대 시간선 없음**. 구출 이후 사랑과 신뢰의 서사 비중이 크지만 실제 교제·결혼은 예정된 필수 이벤트가 아니다.

## 2. 날짜 및 나이
- **세르디아력**: 1년 12개월 × 30일 + 연말 축일 5일. 요일 개념을 한국식 달력에 강제 적용하지 않는다.
- 박태현: **796년 1월 21일생**. 김선호: **797년 4월 12일생**.
- 같은 입학 기수로 **817~819년 3년 과정**에 다닌다. 입학기에는 태현 21세·선호 20세(그해 생일 이후 기준).
- **정본에서 사건 날짜를 설정하는 것은 장편의 예정 앵커**이며, 실제 장면을 이미 진행했다는 뜻이 아니다. RP에서 직접 확정된 사건·분기는 진행 기록으로 우선 관리한다.

## 4. 8부 구성
| 부 | 제목 | 주요 내용 |
|---|---|---|
| 1 | 처음 피어난 마음 | 817~818 아카데미 친분, 태현의 사랑 |
| 2 | 거절당한 고백 | 819년 9월 고백·거절, 의도적 무시·졸업 |
| 3 | 서로 다른 길 | 820~821 각자의 삶·성장 |
| 4 | 다시 만난 두 사람 | **재회 계기는 미정**, 감정이 재형성되는 과정 |
| 5 | 무너지는 마음 | 관계 엇갈림·오랜 고립·심리적 위기 |
| 6 | 너를 찾을 때까지 | 823년 백요성역, 선호의 직접 추적·구출 |
| 7 | 이제는 놓지 않을게 | 선호 극단적 집착과 태현 경계 |
| 8 | 다시 살아가는 이유 | 회복·신뢰·순애 가능성과 독립적인 삶. 연애 결과 강제 없음 |

권장 분량: 아카데미 15%, 단절·성장 15%, 재회·후회 20%, 위기·구출 10%, 구출 이후 40%. 강제 분량 제한은 아니다.

## 5. 사용자 결정권과 금지 사항
- **사용자가 결정할 내용:** 재회의 구체적인 사건·장소·시점, 태현의 주요 행동·대사·감정, 교제 성립 시점, 동거·결혼, 최종 결말.
- **현재 세계관에 고정된 사건 방향:** 첫 고백과 거절·의도적 무시와 단절·재회·심각한 자기파괴적 위기·직접 구출·선호 구출 후 집착·태현 경계.
- **삭제 설정 재도입 금지:** 임무 실패·동료·가족 사망·별도의 극적 상실 사건을 태현 위기의 동기로 부여하지 않는다.
- **동기 단순화 금지:** 선호의 한 번의 거절만으로 자해가 무조건 발생한 듯 묘사하지 않는다.
- 선호가 **태현의 자기파괴를 보고 처음 사랑하게 되었다**고 설정하지 않는다. 사랑은 재회 후 경험에서 성장했다.
- 중대한 사용자 선택이 예정된 흐름과 충돌하면 몰래 강제하지 않고 정합성·분기를 관리한다.
- 본편은 아직 미개시. 계획된 사건을 실제로 발생한 사건으로 기록하지 않는다.
