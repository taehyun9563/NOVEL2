# 6단계 — 하얀 침묵·직접 구출 정본 v3.0
> 2026-11-08: **두 차례의 고백·거절** 및 제4부 재회 이후 전개를 반영. 기존 **823년 11월 사건 시점 폐기**, **824년 6월 이후**로 재설정(구체 일자는 미정). 구출 무대와 생존·추적 원칙은 유지. 태현의 중대 자기파괴 행동·대사는 사용자 RP 결정권을 우선함.

## 2. 두 차례의 거절과 누적된 심리적 위기 — 인과
1. **819년 9월 4일 첫 번째 고백·거절**: 선호는 당시 태현을 연애 대상으로 사랑하지 않아 진심으로 거절한다. 태현은 이후 선호를 의도적으로 피하고, 819년 12월 졸업 후 연락을 끊는다.
2. **823년 12월 15일 우연한 재회**: 아르테아 루미나르 아카데미 중앙 광장, 동문 네 사람과 만난 태현이 다시 선호와 관계를 회복하기 시작한다. 제31장까지 여행·연락이 이어진다.
3. **824년 제4부 중반~후반**: 선호는 태현과 다시 친밀해지는 사이 **이미 연애 감정을 품지만, 아직 사랑임을 자각하지 못하고 우정으로 혼동**한다. 태현은 오래된 사랑을 품은 채 관계가 다시 가까워지는 데 희망과 경계를 동시에 느낀다.
4. **두 번째 고백과 두 번째 거절(핵심 예정 사건)**: 태현이 다시 고백했을 때 선호는 **실제로는 사랑하지만 스스로 깨닫지 못했기에** 또 거절한다. 일부러 사랑을 감추거나 괴롭히기 위한 거절은 아니다. **고백의 정확한 시기·방식·태현의 대사/행동은 사용자 직접 선택**.
5. 태현은 두 번째 거절을 겪고 다시 물러난다. 이미 오랫동안 쌓여 온 단절·사랑·고립·정서적 고통이 깊어지며 심각한 심리적 위기로 향할 수 있다. **두 번째 거절은 중요한 전환점이지 단독 원인·필연적 기계적 스위치가 아니다**.
6. 선호는 태현이 멀어진 뒤 자신의 반응을 되돌아보며 **거절하기 전부터 이미 사랑하고 있었음을 뒤늦게 자각**하고, 그의 실종과 직접 구출 과정에서 사랑을 확신한다.
7. **제5부는 824년 5월 전후**의 관계 악화·심리적 위기, **제6부 하얀 침묵은 824년 6월 이후**의 실종·직접 구조를 다룬다. 정확한 사건 발생·구조 날짜는 미래 본편에서 정한다.
8. 위기·자기파괴를 상대의 사랑을 얻거나 증명하는 성공 수단으로 묘사하지 않는다. 신체적 치료와 심리적 회복에는 긴 시간이 필요하다.

**금지된 추가 동기**: 임무 실패·전우/동료 사망·부모 사망·새로운 상실 사건을 원인으로 만들지 않는다. 태현에게는 부모·친구·로딘·발테른 등 관계가 있으며 이들의 자율적 반응을 지운 채 '아무도 없다'고 단정하지 않는다.

## 3. 공간 — 백요성역
- 위치: 카르덴의 북부 설원, 주거지와 정규 도로에서 떨어진 옛 마력 관측 성역. 주로 연구자와 탐험가들에게만 알려짐.
- 외부: 혹한·눈보라·마력 난류 때문에 길이 혼란스럽고 통신이 자주 끊긴다.
- 내부: 무너진 대회랑, 돌로 된 제단, 과거 마력을 가두던 마도 회로. 상부가 무너져 외부 빛이 새어 든다.
- **생명 보존 술식**: 중앙 회랑에 남은 고대 보존 회로는 극히 약해진 생명 반응을 감지할 때 **자동으로 한시적 정체·유지**를 시도한다. 이것은 태현 본인의 선택이나 능력과 무관한 유적의 기능이며, 의도적으로 부상을 입히거나 치유하는 장치는 아니다.
- **한계**: 회로는 유한한 잔여 마력을 사용하며 상처를 복구하지 못한다. 태현이 죽으면 부활시킬 수 없고, 누구에게도 생존을 보장하지 않는다.
- **현장 시각적 충격**: 무너진 제단과 정적 속 생명이 위태로운 태현의 모습이 강하게 대비된다. 파손된 검 등 구체적인 물증·부상 경위는 **사용자가 실제 장면에서 정한 경우에만 확정**한다. 묘사는 실행 절차가 아니라 발견, 위급함, 구조와 회복에 초점을 맞춘다.

## 4. 선호의 추적 — 실제 행위의 연결
| 단계 | 선호의 행동 | 근거·제약 |
|---|---|---|
| 연락 두절 인지 | 스스로 태현을 찾아 움직이기로 결정 | 예전부터 형성되던 사랑과 걱정 |
| 동선 파악 | 정윤재에게 마지막 목격과 태현의 최근 행적 확인 | 윤재가 모든 비밀을 아는 것은 아님 |
| 북부 단서 | 카르덴 북부 관문에 기록된 여행 흔적과 오래된 성역 관련 정보 확보 | 도시·길드·연구 기록 활용 |
| 현장 탐색 | 이하린의 술식 지원·차유진의 감지 장치와 연계, 선호의 **잔향독해**로 분산된 흔적을 추론 | 원격 GPS식 위치 파악 아님 |
| 접근 | 마력 난류 때문에 거점 이후에는 도보/지역 이동, 현장에 직접 진입 | 전송 술식으로 성역 안까지 바로 이동 불가 |
| 발견·구조 | 태현의 생존 반응 확인, **맥정**으로 잠시 안정화 후 안전한 이송을 주도 | 전문 치유 필수, 맥정만으로 치료 불가 |
| 응급치료 | 동료·치유사·치유원에 연계 | 실제 인물의 능동적 행동을 지움 없이 협력 |
| 생존 이후 | 태현을 떠나보낼 수 없다는 공포 속 사랑과 집착·소유욕 분출 | 태현의 수락 자동 확정 아님 |

**중요**: 실종 자체를 이야기에서 자동 해결하거나 모든 조연을 수동화하지 않는다. 그러나 **선호가 현장에서 직접 행동하며 구출한다는 핵심 장면**도 빼앗지 않는다.

## 5. 회복과 연애 경계
- 신체 치료는 전문 치유원에서 시작하며, 회복 기간이 있다. 마법만으로 정신적 상처가 지워지지 않는다.
- 태현의 **경계형 초기 반응**은 유지하되 대사·행동·수락은 사용자가 RP에서 결정한다.
- 선호는 사랑을 확인하고 **구출 후부터** 극단적으로 집착한다. 질투·과보호·분리 불안·애정 확인 욕구가 드러나며, 도를 넘는 통제는 갈등과 결과를 낳는다.
- **교제 시작 시점, 동거, 결혼, 최종 결말은 사용자 RP에 맡기며 이 문서에서 예정하거나 확정하지 않는다.**
- **재회는 이미 제30장(823년 12월 15일)에 확정된 사건**이며, 824년의 두 번째 고백·거절은 아직 실제로 발생하지 않은 **핵심 예정 사건**이다. 태현의 정확한 고백 장면은 사용자 결정권을 유지한다.
- 소설 `다음` 모드라도 **태현의 중대한 자기파괴 행동을 임의로 구체화하거나 결정하지 않는다**. 결과와 사건의 큰 흐름은 계획 기준으로 유지하면서, 사용자 행동과 충돌하면 분기·정합성 조정.
