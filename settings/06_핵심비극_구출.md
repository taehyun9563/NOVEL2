# 6단계 — 태현의 자기파괴적 위기·선호의 직접 구출 확정 설계 v2.0
> 2026-11-08: 사용자가 재회 계기·교제·결혼·결말을 제외한 미정 설정의 결정을 위임함. 따라서 **구출 무대, 판타지적 생존 조건, 기본 추적·구조 구조는 확정**. 태현의 **구체적 중대 행동과 대사**는 하이브리드 RP 조작권을 존중함.

|---|---|
| 가칭 | **하얀 침묵** |
| 시기 | **대륙력 823년 11월** (기준 연표; 실제 RP의 확정 날짜는 진행에 맞춰 기록) |
| 태현 | **27세·3경지 상위 검사**. 감정적 고립과 위기, 스스로 초래한 심각한 부상 |

## 2. 태현의 심리적 위기 — 인과
1. 학원 3학년 때 태현이 선호에게 진심으로 고백, 선호는 당시 사랑이 없어 거절.
2. 태현은 남은 학업 기간 의도적으로 선호를 무시. 졸업 후 각자 살아감.
3. 재회 후 태현의 남은 사랑과 경계, 선호의 뒤늦게 형성되는 사랑이 어긋남. **재회 방법·정확한 시기는 미정**.
4. 두 사람의 대화 부재·거리감·오랜 감정과 태현의 점진적 고립이 누적되어 위기가 깊어짐.
5. 태현이 삶의 의지를 잃고 심각한 자기파괴적 위기에 이르며, 세상과 연락을 끊음.
6. **이 사건은 거절 한 번 때문에 발생한 필연적 결과가 아니며**, 사랑을 얻는 수단이나 긍정적 보상으로 묘사하지 않는다.
7. 이 위기와 구조 이후에도 태현의 실제 회복 과정과 인간관계는 긴 호흡으로 다뤄진다.

**삭제된 동기 재등장 금지:** 부상 전 마지막 임무 실패, 전우 사망, 부모의 죽음, 추가적인 이별·상실을 위기 촉발의 필수 사건으로 만들지 않는다. 재고백·재거절도 사용자 및 선호의 실제 감정에 달린 조건부 사건이다.

## 3. 공간 — 백요성역
- 위치: 카르덴의 북부 설원, 주거지와 정규 도로에서 떨어진 옛 마력 관측 성역. 주로 연구자와 탐험가들에게만 알려짐.
- 외부: 혹한·눈보라·마력 난류 때문에 길이 혼란스럽고 통신이 자주 끊긴다.
- 내부: 무너진 대회랑, 돌로 된 제단, 과거 마력을 가두던 마도 회로. 상부가 무너져 외부 빛이 새어 든다.
- **생명 보존 술식**: 중앙 회랑에 남은 고대 보존 회로는 극히 약해진 생명 반응을 감지할 때 **자동으로 한시적 정체·유지**를 시도한다. 이것은 태현 본인의 선택이나 능력과 무관한 유적의 기능이며, 의도적으로 부상을 입히거나 치유하는 장치는 아니다.
- **한계**: 회로는 유한한 잔여 마력을 사용하며 상처를 복구하지 못한다. 태현이 죽으면 부활시킬 수 없고, 누구에게도 생존을 보장하지 않는다.
- **현장 시각적 충격**: 무너진 제단, 파손된 검들, 정적 속에 중상을 입은 태현의 모습이 강하게 대비된다. 장면은 구체적인 자해 절차 대신 발견 상태와 구조의 긴박함을 중심으로 묘사한다.

## 4. 선호의 추적 — 실제 행위의 연결
| 단계 | 선호의 행동 | 근거·제약 |
|---|---|---|
| 연락 두절 인지 | 스스로 태현을 찾아 움직이기로 결정 | 예전부터 형성되던 사랑과 걱정 |
| 동선 파악 | 정윤재에게 마지막 목격과 태현의 최근 행적 확인 | 윤재가 모든 비밀을 아는 것은 아님 |
| 북부 단서 | 카르덴 북부 관문에 기록된 여행 흔적과 오래된 성역 관련 정보 확보 | 도시·길드·연구 기록 활용 |
| 현장 탐색 | 이하린의 술식 지원·차유진의 감지 장치와 연계, 선호의 **잔향독해**로 분산된 흔적을 추론 | 원격 GPS식 위치 파악 아님 |
| 접근 | 마력 난류 때문에 거점 이후에는 도보/지역 이동, 현장에 직접 진입 | 전송 술식으로 성역 안까지 바로 이동 불가 |
| 발견·구조 | 태현의 생존 반응 확인, **맥정**으로 잠시 안정화 후 안전한 이송을 주도 | 전문 치유 필수, 맥정만으로 치료 불가 |
| 응급치료 | 동료·치유사·치유원에 연계 | 실제 인물의 능동적 행동을 지움 없이 협력 |
| 생존 이후 | 태현을 떠나보낼 수 없다는 공포 속 사랑과 집착·소유욕 분출 | 태현의 수락 자동 확정 아님 |

**중요**: 실종 자체를 이야기에서 자동 해결하거나 모든 조연을 수동화하지 않는다. 그러나 **선호가 현장에서 직접 행동하며 구출한다는 핵심 장면**도 빼앗지 않는다.

## 5. 회복과 연애 경계
- 신체 치료는 전문 치유원에서 시작하며, 회복 기간이 있다. 마법만으로 정신적 상처가 지워지지 않는다.
- 태현의 **경계형 초기 반응**은 유지하되 대사·행동·수락은 사용자가 RP에서 결정한다.
- 선호는 사랑을 확인하고 **구출 후부터** 극단적으로 집착한다. 질투·과보호·분리 불안·애정 확인 욕구가 드러나며, 도를 넘는 통제는 갈등과 결과를 낳는다.
- **교제 시작 시점, 동거, 결혼, 최종 결말은 사용자 RP에 맡기며 이 문서에서 예정하거나 확정하지 않는다.**
- **재회 계기와 정확한 재회 장소는 의도적으로 공란**. 이전 고백·거절 뒤 두 사람이 어떻게 마주칠지는 별도 사용자 결정 영역이다.
- 소설 `다음` 모드라도 **태현의 중대한 자기파괴 행동을 임의로 구체화하거나 결정하지 않는다**. 결과와 사건의 큰 흐름은 계획 기준으로 유지하면서, 사용자 행동과 충돌하면 분기·정합성 조정.
