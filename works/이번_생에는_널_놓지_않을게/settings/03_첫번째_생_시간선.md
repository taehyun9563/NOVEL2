# 03. 첫 번째 생(2023~2030) 고정 시간선 v2.0

> 아래 사건은 **회귀 이전 실제로 있었던 첫 번째 생의 과거**다. 두 번째 생에서 자동 재현되는 운명이 아니다.

| 날짜·시기 | 사건 |
|---|---|
| 2023.03.13 | 한빛IT아카데미 웹개발 실무 8개월 과정 개강. 태현·선호 처음 만남. |
| 2023.03~09 | 태현의 6개월 짝사랑. 선호는 호의를 느끼지만 자신의 감정 확신이 없어 거리를 둠. |
| **2023.09.15** | 태현이 진심으로 고백. 선호가 사랑할 자신이 없다며 거절. |
| 2023.09~11 | 개인적 연락·식사·친밀감 단절. 학원에서는 필요할 때만 수업 관계로 마주침. |
| 2023.11.10 | 학원 수료. 이후 태현과 선호 사이 직접 연락 없음. |
| 2024~2026 | 각자 IT 분야 취업·사회생활. 선호는 후회가 쌓이지만 체면과 두려움으로 먼저 연락하지 않음. |
| 2027 | 태현이 서비스 기획자 윤서아와 자연스럽게 만나 교제 시작. |
| 2028~2029 | 태현과 서아의 안정적인 관계. 선호는 이 관계에 개입하지 않음. |
| **2030.10.18** | 공통 지인에게서 태현이 결혼 예정이라는 소식을 듣고 커플 사진을 봄. 늦게 자신의 상실을 명확히 직시. |
| **2030.10.23** | 선호가 우연한 교통사고로 사망. 음모·의도된 자해·회귀 실험과 무관. |
| **2023.09.14** | 선호는 고백 하루 전 자신의 몸으로 회귀해 눈을 뜸. |

## 심리적 맥락
- 첫 생 태현은 거절 후 자기 삶을 살았고, 2030년의 약혼은 실제로 쌓아온 새로운 사랑의 결과다.
- 선호는 태현을 7년 내내 적극적으로 사랑한 것이 아니다. 상실감은 점진적으로 쌓이고, 결혼 소식이 그것을 확정한다.
- 선호와 태현은 7년 동안 **직접 연락하지 않은 남남**이나, 공통 학원 지인은 있을 수 있다.
- 결혼 예정은 결혼 완료가 아니다. 선호가 사고를 당한 시점에는 결혼식을 치르지 않았다.
- 회귀 후에는 이 시간선이 반드시 재현되지 않는다.
