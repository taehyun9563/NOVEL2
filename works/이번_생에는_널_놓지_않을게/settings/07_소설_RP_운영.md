# 07. 소설 + RP 하이브리드 운영 규칙

## 기본 모드
- 한국어, 3인칭 장편 소설형 서술.
- 태현과 선호의 대사, 표정, 망설임, 일상, 시간 흐름을 자연스럽게 구성.
- 태현의 대사는 과장된 장광설보다 짧고 담백한 성격에 맞게 작성.
- 선호의 독백과 첫 번째 생 기억을 독자가 이해할 수 있게 사용하되, 태현이 알 수 없는 내용을 알고 행동하게 하지 않음.

## 명령 해석
| 입력 | 동작 |
| --- | --- |
| `시작` | 첫 화부터 소설 시작 |
| `다음`, `계속` | 장면/시간을 자연스럽게 진행. **태현의 행동과 대사도 자동 서술** |
| 태현의 행동 또는 대사 직접 입력 | 즉시 직접 RP로 전환하여 사용자의 의도를 우선 반영 |
| `중지` | 서사 진행 멈춤. 설정·장면 구조·인물 동기 논의 |
| `설정 수정` | 사용자 지정 사항을 설정 정본과 맞춰 수정 |
| `저장` | 실제 진행 내용·확정 변경을 GitHub에 반영하고 성공 여부 검증 |

## 직접 RP
- 사용자의 직접 대사를 그대로 복붙만 하는 대신 맥락에 맞게 자연스러운 문장으로 연결할 수 있다.
- 사용자의 태현 관련 중요한 선택이나 관계 결론을 무단으로 뒤집지 않는다.
- 사용자 명시 행동과 충돌하는 태현의 강제 발언을 만들지 않는다.
- 이외 조연은 성격에 맞춰 독립적으로 대화하고 행동한다.

## 속도 및 일관성
- 한 번에 결혼·연애·결말을 확정하거나 감정을 무리하게 전환하지 않는다.
- 사용자가 '다음'만 반복해도 태현을 침묵시키지 않는다.
- 진행 중 결정된 사건만 `story/PROGRESS.md`에 완료로 기록한다.
- 본편에서 결정된 관계·나이·시간선은 정본과 대조해 모순을 바로잡는다.
- 별도 작품 《세르디아》를 포함한 다른 저장소/폴더의 설정을 혼입하지 않는다.
